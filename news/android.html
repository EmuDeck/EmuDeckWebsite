Introducing EmuDeck for Android

Play your favorites classics in your Android Handheld without hassle, EmuDeck Style!

Customised emulators

In order for EmuDeck to be able to set up the emulators for you we've had to fork some emulators to apply some changes, those changes have been sent to the devs of each emulator so we expect those changes to be made available for everyone in the future! Until then we'll do our best to maintain them up to date.

RetroArch Fork

RetroArch has been forked so we can sideload cores, no need to manually install them anymore!

Cemu, Dolphin and NetherSX2 Forks

These emulators have been forked so their data are stored in a non sandboxed folder so we can change settings and sync their saves using EmuDeck's CloudSync.

Pegasus Companion

We ship EmuDeck Android with Pegasus Frontend as the default rom launcher, everything preconfigured so you only worry about which game to pick. And accompanying it we've developed Pegasus Companion so you can download your games artwork and manage your amazing Pegasus Themes from your Android Handheld, no PC required.

But if you want, you can use any other Android launcher of your choice, EmuDeck is compatible with other options*

* RetroArch core sideloading only works on Pegasus, if you use other launchers you'll need to manually download your RetroArch cores.


Early Access temporary exclusive

EmuDeck for Android will be free just like regular EmuDeck is but for now, in its beta state, is only available for our patrons. You can get it today by joining our Patreon.

CloudSync

Besides EmuDeck Android, Early Access also gives you access to CloudSync, allowing you to sync your saved games between EmuDeck installations.
